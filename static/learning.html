Reference learning / evidence boundary

系统从什么证据中学习？

这个模型学习的是用户提供的正面案例中反复出现的色彩分布。它将这些颜色压缩成一个可检查的参考记忆，再与当前画面中的局部色差共同提出候选区域。

学习过程

每一步都可以被检查和复现。当前方法借鉴正常样本异常检测的“记忆库”逻辑，但使用可解释的颜色区域，而不是不可见的深度特征。

01

正面案例

输入经用户选择的古镇色彩参考图。

02

区域分割

SLIC 将每张图片划分为保持空间连续性的颜色区域。

03

感知色彩

每个区域转换到 CIELAB，并计算中位颜色和面积。

04

平衡记忆

每张图贡献相同权重，减少天空或大墙面的支配。

05

留一校准

每张参考图都与其余参考图比较，建立新颖度基线。

06

证据融合

参考新颖度与当前画面的局部色差共同决定候选排名。

证据边界

这些限制不是附注，而是模型输出的一部分。候选区域必须由人进一步解释、验证和讨论。

下一步需要什么证据？

扩大参考图数量并不自动等于更可靠。数据还需要覆盖不同季节、天气、设备和利益相关者。

    开源研究路线

    我们采用了正常样本异常检测的核心思想，但当前先实现轻量、可解释的颜色记忆。当数据规模扩大后，可以用深度 patch 特征做对照实验。

    PatchCore

    以正常图像 patch 特征建立代表性记忆库，再用最近邻距离定位异常。

    Official repository ↗

    Anomalib

    集合 PatchCore、PaDiM 等视觉异常检测方法，适合未来统一基准测试。

    Official repository ↗

    DINOv2

    提供无需任务微调的通用视觉特征，可在更大数据集上补充物体与材质语义。
